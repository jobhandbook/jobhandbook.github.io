관리자 모드를 켜려면 Supabase 연결이 필요합니다

무료 플랜이면 충분합니다. 한 번만 설정하면 이 페이지에서 일정 · 라운지 답변 · 댓글 · 신청/문의 · 글 관리를 직접 하실 수 있습니다.

  1. supabase.com에서 가입 후 New project.
  2. SQL Editor에서 supabase/schema.sql → notify.sql → lounge.sql 순서로 Run.
  3. Authentication → Users → Add user에서 관리자 이메일 · 비밀번호를 만듭니다.
  4. Project Settings → API의 URL과 publishable 키를 js/config.js에 넣습니다.
