관리자 모드를 켜려면 Supabase 연결이 필요합니다

무료 플랜이면 충분합니다. 한 번만 설정하면 이 페이지에서 일정 · Q&A 답변 · 신청/문의 확인 · 글 관리를 직접 하실 수 있습니다.

  1. supabase.com에서 가입 후 New project (이름 자유, Region은 Northeast Asia (Seoul) 권장, 비밀번호는 메모).
  2. 왼쪽 메뉴 SQL Editor → New query → 사이트 폴더의 supabase/schema.sql 내용을 전부 붙여넣고 Run.
  3. Authentication → Users → Add user에서 관리자 이메일 · 비밀번호를 만듭니다 (Auto Confirm 체크). 이 계정으로만 로그인됩니다.
  4. Project Settings → API에서 Project URL과 anon public 키를 복사해 js/config.js에 붙여넣습니다.
  5. 이 페이지를 새로고침하면 로그인 화면이 보입니다.

anon 키는 공개되어도 괜찮은 키입니다(읽기 · 제출만 가능하도록 DB 규칙이 잠겨 있습니다). service_role 키는 절대 넣지 마세요.
